## 🔐 Overview

**WKT12StealthCPX** injects encrypted content into TCP SYN packets and cloaks handshake metadata for stealth‑grade network operations.  
Featuring a toggleable GUI, encrypted audit logging, and integration with your **AdminHash** module, this tool transforms how packets whisper across the network.

---

## 🎛️ GUI Features (Android APK)

| Button | Function |
|:--|:--|
| 🚀 **Launch Stealth Injection** | Activates SYN packet injector and handshake encoder |
| 🧾 **View Log** | Displays latest encrypted TCP logs |
| 🔒 **Enable Admin Gate** | Requires AdminHash verification before launching |
| ⚙️ **Settings** | Configure retries, delays, and log behavior |
